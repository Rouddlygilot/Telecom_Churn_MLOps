# Telecom Churn MLOps

## Description

Projet d'industrialisation d'un modèle de Machine Learning pour la prédiction du désabonnement des clients télécom.

L'objectif est de développer, déployer et surveiller une application de prédiction du churn à l'aide des pratiques MLOps.

## Technologies utilisées

- Python
- Scikit-learn
- FastAPI
- Docker
- Streamlit
- Git
- GitHub

## Fonctionnalités

- Préparation et traitement des données.
- Entraînement d'un modèle de Machine Learning.
- Évaluation des performances du modèle.
- Déploiement du modèle avec FastAPI.
- Conteneurisation avec Docker.
- Suivi des prédictions avec un tableau de bord Streamlit.
- Gestion du code source avec Git et GitHub.
- Tests automatisés avec Pytest
